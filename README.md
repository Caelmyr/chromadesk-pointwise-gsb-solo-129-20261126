# ChromaDesk 纸层析判读台

打开本地扫描图，标记加样原行、湿线、有效量带和一块未显色的清纸。工作台从扫描图读取像素，保留每一张的已采用设置，并把量带和轨迹交给下一道复查。页面带可重复使用的程序合成练习。练习不代表实测。

```sh
docker compose up --build --wait
```

点开 http://127.0.0.1:19932/ 。用 `docker compose stop` 停止，保留名为 `inspections` 的数据卷。用 `CHROMADESK_PORT` 改宿主机端口。也可以在 Python 3.11 / 3.12 的独立环境中 `python -m pip install -r requirements.txt` 后运行 `./start.sh`，默认绑定 8000 端口，`CHROMADESK_DATA` 可指定数据位置。

1. 导入原片或选择合成练习。用量带与清纸按钮拖框，沿横向湿线和加样线分别点取一行。
2. 采用量带设置。切换光密度，核对识别到的连续色带。纸白按清纸框各通道中位值估计。
3. 点击原片或填原列、原行读取 RGB 与相对光密度。输入目标 Rf 可在原列反查；图表也支持点按回查。
4. 下载量带原片 PNG 或行级轨迹 CSV。送去图像准备会用同一原片建新工程，并保留此层析卡。

读取经 EXIF 方向归一化的 RGB 图。原片左上像素坐标为 (0, 0)，量带框右和下为末像素后边界。当前 Rf 从水平加样线量向水平湿线，只在采用量带与行程内提供。光密度是逐通道 `max(0, log10(清纸值 / 像素值))` 的感知亮度加权，作为同张图的相对指标。轨迹是各原行的跨列平均，色带为连续达到认带门槛的行段，至少三行。照片反光、相机处理、背景阴影及染料混合会改变读数，无材料绝对浓度或光谱推定。

单帧、完全不透明的 PNG、JPEG、TIFF、BMP、WebP。每张至多 14 MiB，边长 24–2300 像素，总像素至多 260 万。一个工作目录至多 48 张层析卡。归档及准备工程使用独立子目录，浏览器只可以访问本机 Compose 指定的端口。
